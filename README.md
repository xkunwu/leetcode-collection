# LeetCode Live-Coding Solutions for University Algorithm Courses

> This repository contains solutions to [LeetCode problems](https://leetcode.com/problemset/) created for use in a university algorithm course. It is maintained as a teaching companion and is updated as the course progresses.

## Overview

The goal of this repository is to support classroom instruction and help students follow the problem-solving process in real time. Each solution is written during live coding demonstrations in class, so the code reflects the instructor’s on-the-spot reasoning and implementation rather than a carefully polished reference solution.

## Purpose

- Provide worked examples for university algorithm course lectures
- Demonstrate problem-solving strategies during live coding sessions
- Help students connect algorithmic concepts with practical implementation
- Serve as a lightweight companion resource that grows with the course schedule

## Important Notes

- **These solutions are written live during class demonstrations.**
- **They may not be the most efficient or optimal solutions.**
- **They are intended for educational use, not as canonical answers.**
- Code quality and style may vary depending on the live-coding context.
- Solutions are added or updated according to teaching progress, not on a fixed release schedule.

Students are encouraged to use these examples to understand the reasoning process, then try to improve the solutions independently.

## Repository Structure

The repository may be organized by topic, week, or problem number as the course evolves. A typical structure may look like this:

```text
.

├── ...
├── topics/
```

The exact structure may change as new lectures and topics are added.

## How to Use

1. Browse the folder corresponding to the current lecture or topic.
2. Read the problem statement on LeetCode.
3. Review the live-coded solution and the accompanying explanation, if available.
4. Try to implement your own solution and compare approaches.
5. Consider optimizing the solution or testing edge cases on your own.

## Updates

This repository is updated alongside the course. New solutions are added when the corresponding topics are covered in class. Some solutions may be revised later for clarity, but they are not guaranteed to be continuously optimized or refactored.

## Contributions and Feedback

This is primarily a course teaching repository. Suggestions, bug reports, and alternative approaches are welcome, but please understand that the main priority is classroom instruction. Pull requests may not be reviewed promptly.

## Disclaimer

This repository is intended for educational purposes only. The solutions are live-coding demonstrations and may contain suboptimal approaches, incomplete optimizations, or stylistic inconsistencies. They should not be treated as definitive or production-ready solutions.
